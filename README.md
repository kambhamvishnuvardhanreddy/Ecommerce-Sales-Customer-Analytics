# E-Commerce Sales & Customer Analytics

## Project Overview

This project analyzes e-commerce sales, customer information, product performance, orders, and payment data using SQL Server and Tableau.

The goal is to explore business data, identify useful trends, and present insights through a Tableau dashboard.

## Tools & Technologies

* SQL Server
* SQL
* Tableau
* CSV datasets

## Datasets

The project includes four datasets:

* Customers.csv
* Products.csv
* Orders.csv
* Payments.csv

## SQL Analysis

SQL was used to explore the datasets and analyze business performance.

Key activities include:

* Database and table creation
* Data analysis using SELECT queries
* Combining tables using JOINs
* Aggregations and summary calculations
* Sales and customer analysis
* Order and payment analysis

## Tableau Dashboard

The Tableau dashboard presents e-commerce performance through visualizations and KPIs.

Areas explored include:

* Sales performance
* Customer analysis
* Product performance
* Regional sales
* Payment status and methods

## Project Files

* `Customers.csv` — Customer dataset
* `Products.csv` — Product dataset
* `Orders.csv` — Order dataset
* `Payments.csv` — Payment dataset
* `sql ecommerce_analytics.sql` — SQL queries
* Tableau workbook — Interactive dashboard

## Skills Demonstrated

* SQL querying and JOINs
* Data analysis
* Data preparation
* Data visualization
* KPI reporting
* Tableau dashboard development

## How to Use

1. Download the project files.
2. Import the CSV datasets into SQL Server.
3. Execute the SQL script.
4. Open the Tableau workbook.
5. Update the data connection if required.

## Conclusion

This project demonstrates how SQL Server and Tableau can be used together to analyze e-commerce data and present business information through interactive visualizations.
